# Bajpayee Kachodi Bhandar — Website

A one-page website for Bajpayee Kachodi Bhandar, an iconic breakfast spot in Hazratganj, Lucknow, serving Kachodi, Khasta Kachori, Chole Bhature and Poori-Sabzi since the 1970s.

- Address: Naval Kishore Road, near Cathedral School, opposite Bank of India, Hazratganj, Lucknow 226001
- Phone: +91 91407 85587
- Hours: Monday–Saturday 7:30 AM – 7:30 PM; Sunday 7:30 AM – 3:30 PM

Built as a single static `index.html` (Tailwind via CDN). Details are taken from public listings (Zomato, Restaurant Guru, Magicpin) and can be updated by the owner at any time.
